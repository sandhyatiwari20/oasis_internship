# Oasis Infobyte Internship Tasks

This repository contains my work completed during the Oasis Infobyte Data Science Internship.

## Tasks Completed

### Task 1 – Retail Sales EDA
Exploratory Data Analysis of retail sales data using Python, Pandas, Matplotlib, and Seaborn.

Data cleaning and preprocessing using Python and Pandas, including handling missing values, duplicates, data types, and outliers.
